# 🌤️ Thiranex Task 4 – Weather Dashboard

A responsive Real-Time Weather Dashboard developed as part of the Thiranex Internship – Task 4: Asynchronous JavaScript & RESTful APIs.

## 🌐 Live Demo

👉 https://divyabanuka.github.io/Thiranex_Task4_Weather_Dashboard/

## 📌 Project Overview

This project is a real-time weather dashboard that allows users to search for any city and view current weather information.

The dashboard displays:

- 🌡️ Temperature
- ☁️ Weather Condition
- 💧 Humidity
- 💨 Wind Speed
- 🌡️ Feels Like Temperature

## ✨ Features

- 🔍 Search weather by city name

## 🔄 How It Works

User enters a city
↓
JavaScript validates the input
↓
City coordinates are retrieved
↓
Weather data is fetched
↓
JSON response is processed
↓
Weather information is displayed

## 📊 Weather Information

| Metric | Information |
|---|---|
| Temperature | Current temperature in °C |
| Weather | Current weather condition |
| Humidity | Relative humidity percentage |
| Wind Speed | Wind speed in km/h |
| Feels Like | Apparent temperature in °C |

## ❌ Error Handling

The application handles:

- Empty city input
- Invalid city names
- City not found
- Failed API requests
- Network errors

Example:

City not found. Please enter a valid city name.
